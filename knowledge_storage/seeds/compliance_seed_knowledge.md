# 跨境电商法规种子数据（合规法规精简版样例，**仅用于演示流程，非官方文本**）
# 实际项目应当接入已审核的法规全文。

## CE-RED (欧盟无线设备指令 2014/53/EU)

适用范围：欧盟成员国市场上销售的无线设备（蓝牙、Wi-Fi、RFID、蜂窝、433/868MHz 等）。

主要检测项目：
- EMC（电磁兼容）
- RF（射频性能，EN 300 328 / EN 301 893）
- EMF（电磁场暴露，EN 62479）
- LVD 安全（EN 60950-1 / EN 62368-1）
- 频谱效率

典型品类举例：
- 蓝牙耳机：CE-RED + EMC + RF
- 智能音箱：CE-RED + LVD + EMF
- 工业传感器：CE-RED + EMC + 户外环境测试

## RoHS (有害物质限制指令 2011/65/EU + (EU) 2015/863)

适用范围：在欧盟销售的电气电子设备。

限制物质（10 项）：
- 铅 (Pb) ≤ 0.1%
- 汞 (Hg) ≤ 0.1%
- 镉 (Cd) ≤ 0.01%
- 六价铬 (Cr6+) ≤ 0.1%
- PBB / PBDE ≤ 0.1%
- DEHP / BBP / DBP / DIBP ≤ 0.1%（四种邻苯二甲酸酯，2019/7/22 起强制）

豁免：医疗、监控、军用、专用大型工业设备等有例外条款。

## UN38.3 (锂电池运输安全)

UN38.3 是联合国《关于危险货物运输的建议书》第 38.3 节。

适用对象：单独运输或随设备运输的锂电池（笔记本电脑、手机、平衡车、储能等）。

测试项目 (T1~T8 + T9)：
- T1 高度模拟（低压）
- T2 温度循环
- T3 振动
- T4 冲击
- T5 外部短路
- T6 撞击
- T7 过充电
- T8 强制放电
- (T9 自反应物质)

未取得 UN38.3 测试报告的锂电池无法通过 IATA 货代上飞机。

## FCC Part 15 (美国无线设备)

适用范围：美国市场上的无意辐射体与有意辐射体。

分两小类：
- Class A：商业/工业用途
- Class B：居住环境

认证方式：
- Supplier's Declaration of Conformity (SDoC)
- Certification (TCB 颁发 ID)

## PSE (日本电气用品安全法)

圆形 PSE：电线、插座等非特定电气用品
菱形 PSE：特定电气用品（AC 适配器、家电等）

## KC (韩国广播通信设备符合性认证)

适用范围：进入韩国市场的无线/通信设备，需要本地测试或 MRA 互认。
